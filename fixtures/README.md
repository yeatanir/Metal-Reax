# fixtures — pinned reference data (M1)
Empty at M0. Layout, content and the noise-floor protocol are specified in `docs/VALIDATION.md` §2 and
`docs/NUMERICAL_POLICY.md` §3. A fixture is hashed in a `MANIFEST.sha256` and is regenerated only with a
`docs/DEVELOPMENT_LOG.md` entry; a mismatch is never resolved by editing a fixture.
